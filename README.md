# 真实资产配置回测 · GitHub Pages

稳定在线地址：<https://bouquett.github.io/ai-portfolio-lab-demo/>

这是不依赖临时应用域名的浏览器端真实数据版本。它支持卡片式配置、代码自动识别、1 / 3 / 5 / 10 年回测、年度再平衡、交易成本、最大回撤和约束优化。每张资产卡片都可以独立展开回溯面板，在 1 / 3 / 5 / 10 年之间切换，查看该基金或证券的标准化走势、年化收益、累计收益、最大回撤、数据区间和来源；真实历史不足的期限会直接禁用，不用短数据伪装长回测。

默认研究方案为 200 万元：固收 110 万（25 万短融、35 万综合债券指数、30 万信用债、20 万纯债，均为场外可申赎份额，分属四家基金公司），A 股宽基 80 万（45 万沪深300、35 万中证500），现金 10 万。按当前研究假设，默认组合暂不配置黄金和标普500；这属于可回测的战术选择，不代表它们长期没有分散价值。默认方案也不含 511220 城投债 ETF、511880 银华日利或 511010 国债 ETF。优化器固定现金 5%、固收 55% 和 A 股宽基 40%，只优化各层内部权重，并限制每项固收为组合的 5%–20%，避免把“最优”误算成单一债券集中持仓。

“不含城投债 ETF”不等于主动债券基金底层始终为零城投敞口。场外债基持仓会变化；若要求绝对排除城投，应按最新季报穿透核验全部债券持仓，或改用只跟踪国债、政策性金融债的产品，并接受可用历史区间可能不足 10 年。

## 数据完整性

- 场外基金：以跨域脚本方式读取东方财富完整累计净值。
- 境内 ETF / 股票：读取腾讯证券前复权日线；ETF 在腾讯失败时可回退到东方财富累计净值。
- SPY：由 GitHub Actions 从 Yahoo Finance 或 Nasdaq 读取真实行情，并结合 USD/CNY 汇率生成同源日更快照。
- 现金：只使用界面中明确给出的年化代理假设。
- 任一市场资产取数失败时停止回测，不生成替代走势。
- 单资产回溯首次展开时读取最长 10 年历史并在本页缓存，切换期限不会重复请求；现金面板始终明确标注为利率代理推算而非行情。

`data/us/SPY.json` 工作日自动更新。若 Yahoo 不可用而使用 Nasdaq 收盘价，页面会显示“不计现金分红”的口径警告。

## 本地运行

```bash
python3 -m http.server 8080
```

打开 <http://localhost:8080/>。直接双击 HTML 会因为浏览器模块安全限制而无法正常工作。

## 验证

```bash
npm test
npm run update-data
```
