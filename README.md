# AI Multi-Asset Portfolio Lab

The former synthetic-data demo is retired. This repository now redirects to the real-market-data application:

https://real-portfolio-lab-cn.fhvwtbfbvg.chatgpt.site/

The application identifies supported fund and security codes, backtests only from retrieved market observations, shows source and cutoff metadata, and fails explicitly when real data cannot be obtained.

Source code for the real application is maintained in a separate private repository. Historical results are research outputs, not guaranteed future returns or investment advice.
